# Some Odd Road — numbered stamp production kit

This ZIP installs source material and instructions under `tools/stamps/` when unpacked at the root of the Jekyll repository. It does **not** replace any website PNG itself.

**Approved series:** 01–99, C059 Bold distressed brick-red numerals, 12-degree counterclockwise tilt, RGBA transparent stamp backgrounds.

**To publish:** separately upload `Some_Odd_Road_C059_stamps_01-99_FINAL.zip` to the Codespace root, unzip it, and preview story pages. Full commands in `tools/stamps/README_INSTALL.md`.

**To reproduce:** use `tools/stamps/generate_stamps.py` and the bundled PNG masters; no font files required.

**100–200:** three-digit geometry is experimental; review samples before extending.
